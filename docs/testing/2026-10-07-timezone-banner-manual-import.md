# 时区横幅与手动导入旧对话

## 交付

- 时区异常使用页面顶部可关闭横幅，`role=status`、`aria-live=polite`，不弹窗、不抢焦点，不增加启动探测请求。
- 在实际日程请求或设置读取中发现无法识别时区、客户端不支持时区、设置与生效时区不一致时提示；用户选择不同于系统的合法时区不误报，IANA 别名按等价处理。
- 关闭状态按后端隔离，在当前窗口会话内跨刷新保留。相同异常轮询不重复打开；检测恢复后清除，之后新异常可再提示。
- 设置 → 系统设置 → 旧版对话迁移：增加“导入旧版对话”按钮。扫描已有 SQLite/Pi 导出源，转换到 K-brain 历史存储，不删除源文件，不覆盖已有会话，不重建已标记删除会话。
- 显示运行中、新增、已存在、失败数量及可展开失败详情；文件回滚记录不完整单独说明。支持重试、重复点击合并、切换页面后保留结果。
- 导入完成刷新侧栏会话与项目目录；浏览器展示禁用按钮并说明需要在保存旧数据的桌面端操作。

## 验证

- 前端 2,975 项：2,974 通过、1 跳过、0 失败；TypeScript 检查通过。
- 单元测试覆盖提示去重/关闭/刷新恢复/后端隔离、IANA 别名、合法自定义时区、不匹配恢复、导入并发/失败/重试/浏览器限制。
- Chrome + 真实 K-brain：无效日程时区显示横幅，点击进入时区设置，关闭后设置轮询及刷新不重新提示。390px 移动布局无水平溢出，关闭按钮可用。
- 浏览器模拟时区设置返回不匹配，验证横幅显示两个时区；恢复一致后自动清除，系统时区不同不误报。
- Mac 原生 WKWebView + 真实 K-brain + 隔离旧 SQLite：应用启动后写入测试旧会话，点击按钮显示“新增 1 条”；第二次显示“已存在 1 条”。后端历史接口 200，正文保留；侧栏自动出现迁入项目和会话，可打开旧正文。
- 测试目录 `/private/tmp/history-acceptance`；未触碰用户正式数据库，未替换正式安装。

## 边界

- 历史导入从既有默认旧版数据源扫描，不包含任意路径文件选择器。
- 关闭提示不代表修复无效时区；日程页原有错误/重试仍保留，聊天可继续使用。
- 手动导入复用现有迁移的删除标记边界：早于删除标记实现的历史删除，无法与丢失的迁移目标可靠区分。
- 本轮不发版；已发布 beta 附件不变。
