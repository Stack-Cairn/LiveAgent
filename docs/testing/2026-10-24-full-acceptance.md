# LiveAgent / K-brain 完整验收记录

## 结论

本轮完成剩余清单的可执行验收，并修复实际发现的缺陷；**整体尚不满足全功能验收通过条件**。SSH/隧道仍由桌面原生端执行，语音仍由 Gateway 执行；私有日历双向同步、真实供应商生成/识别、通知横幅、Windows 实机和原生拖拽不能由本轮测试代替。

测试使用隔离的 macOS `.app`、KB、Gateway、Chrome 1440×950 / 390×950；数据放在 `/tmp/la-full-audit`，证据放在 `/tmp/la-acceptance-final`。没有修改真实用户会话或系统权限，没有读取私人服务密钥。协议测试服务明确与商业供应商验收区分。

## 本轮修复

1. KB 增加文件创建、带版本校验的文本重写、目录创建、重命名、非递归删除及预览读取。Gateway 投影固定请求，不执行文件工具。
2. 修复 Web 文件树双击文本仍转发桌面、显示 `agent offline` 的问题。预览与编辑现在由 KB 文件接口完成。
3. 文件重写要求修改时间和内容摘要；拒绝过期写入及未读取就覆盖。新文件独占创建；macOS/Linux 重命名使用不覆盖目标的系统原语。
4. 项目提示词保存映射到 KB 项目资源；后端摘要中的项目哈希键不再误当作路径。保存客户端路径别名，解决 macOS `/tmp` 与 `/private/tmp` 重载后丢失关联。
5. 提示词页面使用侧栏实际工作空间列表，修复侧栏有项目、设置页却显示零个项目。完整提示词快照支持清除旧缓存；增量语音设置不再重置后端提示词能力。
6. 项目布局留在浏览器；未支持的系统设置或项目资源选择仍交给后端明确拒绝，不返回虚假的保存成功。
7. 移动端打开文件后收起工具面板，避免其遮挡预览和编辑器。
8. DashScope 的消息和读错误使用同一有序队列，避免供应商发送 `task-finished` 后立即关闭连接时，关闭错误抢先覆盖成功结果。增加真实 TLS/WebSocket 协议测试；测试信任仅限临时服务器证书。
9. STT 握手超时通过处理器参数测试，移除全局变量改写造成的测试数据竞争。

## 自动验证与证据

- KB：最终 `go test -p 1 ./...`、`go vet ./...`，backend/planning/resources 的 race 测试通过。
- Gateway：全量测试、vet 通过；STT 修复后 race 测试通过；kbrain/websocket race 通过。
- Web：819 项测试通过；Web、共享 UI、GUI 类型检查通过，Web 生产构建通过。构建保留已有的 ImagePreview 静态/动态导入提示。
- 首次并行 KB 全量测试出现 TUI `TestRunningTaskViewReplaysThenStreams` 5 秒超时；随后串行全量通过，不将这次失败隐去。
- 首次语音 race 验证暴露结束事件乱序及测试超时变量竞争；修复后重新验证通过。
- 最后重复浏览器验收时，本机图像测试服务已停止，任务进入 `result_unknown`；恢复测试服务后两档重新执行通过。断网后的未知结果不自动重发，避免重复收费。
- 主要证据：`acceptance-browser.log`（桌面）、`mobile-browser.log`、`final-pages.log`、`ssh-regression.log`、`tunnel-regression.log`、`calendar-regression.log`、`stt-race-final.log`，以及对应截图。临时文件可能含测试连接配置，不提交原始目录。

## 未通过 / 待补齐

1. SSH/SFTP 和隧道迁入 KB，凭据、权限和生命周期统一；当前原生功能可用不等于架构要求已实现。
2. 私有 Google/iCloud/Exchange 账号订阅及原生双向写回。现实现主要是只读 ICS，无凭据也不能掩盖功能尚未实现。
3. macOS 通知权限、真实系统横幅及后台提醒；原生桌面拖拽未验收。
4. 真实商业图像生成、麦克风录音、商业语音识别及取消/失败恢复；本地协议测试只能证明传输与状态链路。
5. Windows 实机全功能验收。新增独占重命名目前仅 macOS/Linux；其他平台明确返回不支持，不冒险覆盖目标。
6. 文件 ignore 规则、完整图片/附件引用、大文件预览、非空目录删除语义对齐；跨外部进程的写入校验与原子替换之间仍存在竞争窗口，不宣称强事务式保存。
7. 完整模型、MCP、缓存命中、所有 CLI 工具和平台组合的真实账号回归；页面冒烟和旧轮结果不等价于本轮逐项重测。

本轮不创建版本标签、不合并主分支、不以该记录批准发布。
