## 用户可观察场景

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 空状态与首次使用 | 在独立调试环境首次打开工作台 | 直接显示大预览、创作区及历史；无需创建项目。没有模型时说明供应商配置路径，无视频页签 |
| 移除旧入口 | 打开工作台与供应商设置 | 无项目素材栏、版本详情栏、目标设置或独立图像服务页签；原供应商编辑仍可用 |
| 模型刷新 | 添加受支持的图像模型，返回或点击刷新模型 | 显示供应商中的图像模型；已有提示词不丢失；聊天模型不会全量冒充图像模型 |
| 文生图 | 输入下方提示词，选择模型、尺寸和数量后点击生成 | 任务出现在历史，状态更新，成功后大图可预览；无虚构价格 |
| 重复操作 | 对生成快速双击；完成后点再次生成 | 首次只有一个任务；再次生成要求明确确认；新任务不会覆盖旧图 |
| 图生图上传 | 切换图生图，上传 PNG/JPEG/WebP 后描述修改 | 显示输入缩略图；请求带图片；不支持图生图的模型禁用该方式 |
| 拖放与粘贴 | 将图片拖到创作区；复制图片后在输入区粘贴 | 图片进入输入列表，可移除；普通文本粘贴仍正常 |
| 上传期间切换 | 图片上传尚未结束时切换生成方式或模型 | 旧上传被取消；即使迟到返回，也不会加入新输入。仅刷新未改变的模型不会取消上传 |
| 参数边界 | 清空提示词、数量改为 0、超过模型上限，或输入不支持文件 | 提交受阻并显示原因；修正后可继续；草稿保留 |
| 生成失败 | 在测试供应商中使用无效凭据或由测试服务返回错误 | 显示准确错误和供应商检查建议；修改后能恢复；不暴露凭据 |
| 取消 | 使用耗时请求，历史中点取消/停止本地处理 | 显示取消进度及真实效果；若仅本地停止，保留上游可能执行的说明；晚到结果不丢失 |
| 历史筛选 | 搜索提示词或模型，切换有结果/进行中/需关注 | 只显示匹配任务；无匹配时显示空状态；清除筛选可恢复 |
| 历史恢复 | 对历史任务点恢复输入或继续修改，包括旧项目任务 | 恢复原提示词、模型、参数、数量及可用输入；不会自动生成；旧历史仍可见 |
| 页面恢复 | 输入草稿后离开再返回或重启客户端 | 草稿与历史恢复；未确认的原请求显示核对入口，复用原请求身份 |
| 主题与布局 | 分别使用明暗主题，调整到桌面和窄窗口，窄屏打开历史 | 预览、创作、历史清晰可读；控件重排，无横向溢出；键盘焦点可见 |

