# 图像工作台界面约定

本约定将用户提供的参考图与 Vercel design.md 方法应用到 LiveAgent 的既有组件、主题和共享页面。参考 https://vercel.com/blog/how-our-agents-build-on-brand-pages-with-design-md 与 https://vercel.com/design.md；本产品沿用 LiveAgent 品牌，不加载 Vercel 报告样式或标志。

## 使用目标

用户在同一视图描述图片、添加输入、选择已有供应商的图像模型并生成。主视图以图片为中心；输入在预览下方，历史在右侧。图片是唯一页签。项目、执行目标、连接与版本详情不作为创作步骤出现。

## 组件与主题

使用共享 Button、Input、Textarea、IconSet 和现有语义色变量。背景、文本、边框、焦点和状态均继承当前明暗主题。不增加字体、图标库、渐变、装饰动画或外部资源。图片区、创作区和历史区以稳定的间距和一致边界表达功能分组；避免重复说明与装饰信息。

桌面采用主创作列及历史列；主列中预览占据剩余高度。窄屏采用单列，历史按钮控制历史区显示，页面允许垂直滚动，输入与操作重排。每个控件有可访问名称、键盘焦点与明确禁用状态。图片维持比例，不拉伸。

## 行为

复用现有供应商地址与凭据；仅显示可映射到已有图像协议的模型能力。根据真实能力显示文生图、图生图和尺寸参数。图片可上传、拖放或粘贴；输入校验、幂等提交、未知结果核对、取消、历史恢复与草稿保留继续使用现有控制器。

内部项目自动归档，历史包含旧项目，不自动删除。历史可按提示词或模型搜索，并按结果/进行中/需关注筛选。费用未知时不显示推算价格。取消的真实效果及未知结果仍准确告知用户。

## 验证

固定场景为首次空数据、供应商无图像模型、正常生成、图生图输入、参数边界、提交拒绝、丢失回执、重复提交、取消、事件重连、跨历史恢复。使用同一共享页面在桌面、窄屏及明暗主题下检查布局、焦点、溢出和状态。测试夹具与真实供应商人工验收区分记录。
