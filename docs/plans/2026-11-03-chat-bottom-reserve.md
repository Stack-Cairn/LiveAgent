## 问题与实现

输入区高度测量原先扣除队列面板，绝对定位的任务胶囊也不计入正文预留。滚动到会话底部后，最后一段输出因此可能落在这些控件下方。

共享的 `measureComposerOverlay` 现在从整个底部输入区及任务胶囊的最高可见位置测量到输入区底边，包含队列、目标栏、审批栏、输入卡片、状态栏和间隔。桌面端通过高度回调更新正文底部占位；WebUI 将相同结果写入各自会话面板的 CSS 变量。两个宿主共用尺寸观察及按帧合并机制。回到底部按钮使用完整预留高度，删除额外胶囊高度的重复计算。

全屏编辑沿用现有行为：展开和过渡期间保留常规占位，收起结束后重新测量。
