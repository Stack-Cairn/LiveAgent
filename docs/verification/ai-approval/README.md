# AI 智能审批验收（2026-10-11）

## 入口和所有权

LiveAgent **设置 → 系统工具 → AI 智能审批**。提供「关闭」「仅风险提示」「自动审批」和独立审批模型选择。所有配置落在 K-brain 的 `aiApproval`，不写入前端工具运行配置。默认关闭；旧后端明确提示升级，不显示虚假的已保存状态。

桌面通过 `/v1/settings`，WebUI 通过现有 Gateway 设置协议。Gateway 保留审批配置，模型列表只包含启用模型。配套 K-brain v0.107.6-beta.7；LiveAgent v2.0.0-beta.12 的发布下载锁固定该版本源码和各平台 SHA-256。

桌面端风险提示使用通知，人工审批框同时显示命令和风险说明，不拼入助手回答。Gateway WebUI 显示风险状态。其现有传输没有人工审批响应 RPC，本次做了拒绝兜底，避免挂起或静默放行；界面说明需转到桌面端/TUI 确认。这部分不是完整的 WebUI 人工审批 UI。

## 已验证

- GUI 全量测试：3055 通过，1 跳过。
- WebUI 全量测试：771 通过。
- 新增/修改定向测试：设置三模式、模型选择、保存失败/恢复、旧后端提示、审批风险通知、桌面人工确认说明、WebUI 配置透传。
- Gateway K-brain 集成包通过 `go test -race ./internal/kbrain`，包含设置/事件投影和远端无人工确认能力时的拒绝回传。
- GUI/shared UI/WebUI 类型检查和 UI 边界检查通过。
- Chrome 浏览器：在桌面和 WebUI 各自 Vite 宿主中加载真实共享设置组件，HTTP fixture 模拟设置 API，验证 1280px/390px 下三模式保存、刷新后保留、未选模型禁用保存、503 错误恢复、无水平溢出。附四张截图。
- 浏览器 fixture 不是实际 macOS Tauri 安装包或真实云模型联调。启动时发现已有 `userMessageContent.tsx` CSS 字符串触发 Vite 全应用依赖扫描警告；未改这个无关文件，预热后的组件测试无页面错误。

## 后端语义与限制

参见 K-brain `docs/ai-approval.md`。审批独立调用、无工具、严格 JSON、15 秒超时、512 输出 token、每轮 64 次和两路并发限制。常见敏感数据以及已配置凭据先不可逆脱敏；不能保证识别任意秘密。自动模式仅低风险单次放行，不改变沙箱/拒绝策略；异常回人工，非交互 CLI 拒绝。工具文本不可信，图像内容未做视觉审批。

未测试真实远端小模型的判断准确率、实际费用或所有供应商；本次没有使用用户的真实配置、历史记录或密钥，真实云端模型尚未联调。
