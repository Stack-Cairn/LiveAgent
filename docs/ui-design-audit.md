# UI 第一阶段整理记录

当前目标是清理零散样式并保留现有外观，为后续统一设计规范准备基础。
具体变量用法见 [UI 样式变量](ui-style-variables.md)。本文件记录当前实现，
不作为字号、颜色、圆角或间距应当采用哪一档的设计规范。

此前 `feature/ui` 的大范围视觉收敛方案已经回撤。原记录中的固定视觉尺度、
组件样板 `/design.html`、设计审计命令和完成计数不适用于当前代码，已移除。
暂不恢复根目录的设计规范文档。

## 当前整理范围

- GUI、Gateway WebUI 和共享 UI 使用 Tailwind v4 的 CSS `@theme`。
- 原有字号、尺寸、颜色、阴影、断点和动效保留数值；固定样式接入共享变量。
- 标准 Tailwind 类继续使用；特殊尺寸使用 `text-14px`、`h-18px` 等具名类。
- 时间变量统一采用毫秒命名；数值相同的颜色原语合并，阴影和渐变引用这些原语。
- JS 中的斜纹背景改为具名背景类；SSH 面板、楼层导航、快捷键高亮和 Git 图颜色接入变量。
- xterm 通过 `lib/terminal/theme.ts` 读取实际颜色和尺寸；Web Animations 读取实际 easing。
  这两种 API 需要解析后的值，不能直接传入 `var(...)`。
- 继续迁移简单的单处 CSS，同时保留共享规则和第三方节点适配。

## 无消费者样式的确认方式

本轮删除前进行了三层核对：

1. 在仓库中搜索完整类名，区分生产代码、测试、文档和 CSS 定义。
2. 扫描 TS/TSX 字符串与模板片段，检查动态拼接、DOM 查询及直接写入类名的路径。
3. 核对实际渲染组件、第三方依赖及样式入口；关键帧单独检查动画名引用，
   组合选择器只移除失效分支，保留仍在使用的分支。

确认删除了 58 个无消费者类名、118 个选择器分支和 10 个无引用关键帧。
主要涉及以下已失效的实现：

| 旧样式 | 当前消费者核对 |
| --- | --- |
| `checkpoint-status-pulse`、`checkpoint-shimmer` | 检查点卡片使用当前共享组件和展开动效；同前缀动态字符串是消息 ID，不是类名。 |
