# WebUI 工作空间与新会话修复验收

## 范围

基于 LiveAgent `v2-kbrian` 的 `9b01957d`，工作分支 `fix/webui-workspace-chat`。
本报告记录 WebUI 工作空间与会话修复的本地验收；此部分无需修改 K-brain。独立的后台消息计时修复见 `subagent-elapsed-time-2026-10-19.md`。

## 根因与修复

1. K-brain 模式关闭旧前端运行时后，远程聊天也被旧 `gatewayMirror` 能力判断拒绝。原生桌面现在接收显式的 WebUI 请求，再交给 K-brain 执行；本地聊天不会恢复旧运行时或自动镜像。
2. 终止请求失败原来只更新桌面记录，浏览器等到启动看门狗超时才看到通用错误。现在向网关发送带错误码和原因的失败事件；可重试的非终止请求不会误发终止状态。
3. WebUI 模型目录、历史列表和历史内容仍读取旧 SQLite 数据。模型读取改接 K-brain 设置；历史通过桌面已有的请求/响应桥接使用同一个 K-brain 历史适配器和 ID 映射，不复制生成或工具执行逻辑。
4. WebUI 刷新会把历史中的 `session_id` 用作下一次请求目标。面向 WebUI 的摘要保持桌面对话身份，同时接受旧页面保留的后端 ID 别名，避免刷新后追问切换目标。
5. 目录选择默认展开远程主目录，支持输入路径、打开、失败重试；未验证的输入不会误选旧目录。单个子目录条目读取失败不再导致整个父目录枚举失败。Windows 盘符、扩展路径、网络共享使用共享路径比较规则。
