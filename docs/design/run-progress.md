# 运行阶段与首字诊断

K-brain 的 `run.progress` 是主运行阶段的权威来源；LiveAgent 不从模型正文猜测阶段。
Gateway 将阶段放入既有 tool_status 载荷，桌面镜像复用同一格式。前端通过共享组件
显示并本地化，兼容旧后端忽略新增字段、旧客户端忽略新增事件。

阶段：准备运行、压缩历史、等待模型、思考、输出、工具执行、保存结果。
后端计时从执行器开始；客户端计时从 `runKBrainTurn` 调用开始，包括该函数中的
会话创建和运行接收，不冒充点击发送至绘制的耗时。不同机器时钟不相减。
只有主运行事件改变主运行显示。后续工具轮次允许再次进入等待模型。
首次正文、思考计时只记录一次，阶段数据不包含提示词、路径和凭据。

运行中可见阶段和后端耗时；详情提供首次思考、首次正文及客户端收到首段的耗时。
终态清除进行中的提示，既有轨迹保留原本的历史耗时，不创建第二份会话历史。
旧后端至少显示连接、会话准备、思考/输出等本地可确认状态；运行接收成功不冒充模型已开始请求。

连接自动恢复时不重新发送写请求，沿用原运行和事件序号；重连后首个有效事件恢复
之前的活动状态，避免一直停留在“重连中”。取消沿用既有取消接口。
本批不改变重试次数，不增加会重复启动运行的“重发”操作。

验收：桌面和 WebUI、1280 与 390 宽度、中英文阶段/详情、分段输出、重连续传、
取消、错误、旧后端、工具/审批状态不被无关阶段覆盖，以及后续轮次等待状态。
