# Planning 对标 Google Calendar / Tasks

更新：2026-09-27。基线 `main`（`341b005d`），分支 `feat/planning-calendar-main`。
Planning 是把 Google Calendar 与 Google Tasks 合在一个页面里的实现：布局、信息层级、交互、
尺寸比例全部对标 Google；颜色、字体、字号仍使用 LiveAgent 主题 token，保证亮暗主题、
区域字号缩放与用户字体设置继续生效（不复刻 Google 的品牌色值与 Google Sans）。

## 采集方式

在已登录的 Chrome 中打开 `calendar.google.com`（周/月/日程视图、Tasks 侧栏、任务视图）与
`tasks.google.com`，用 DevTools 计算样式读取尺寸、字号、圆角和颜色，只读查看弹窗与菜单，
没有创建或修改任何 Google 数据。下表数值为 1680×873 视口、深色主题下的实测。

## 未对标或刻意不同

- 年视图、4 天/自定义天数视图、预约页面、找人、搜索：Planning 暂无对应数据或需求，未实现。
- Google 任务弹窗中的忙闲、公开程度、组织者：应用未建模这些字段，不展示。
- 任务时间块：Google 任务固定 30 分钟，LiveAgent 保留可拉伸的排期块和多段排期。
- 日程与任务的区分比 Google 更强：日程为实心色块；任务排期块为浅色底 + 左侧 4px 列表色条 + 勾选圆圈；
  有截止时刻的任务与 Google 一致，为单行「○ 标题，hh:mm」胶囊（固定 22px 高、任务列表色填充），浮在日程之上、不挤占日程宽度，仅与相互重叠的胶囊分列；重叠日程按 Google 方式加宽错位叠放，后者带背景色描边。
  月视图对应为色点 / 彩色圆圈 / 虚线框，日程视图任务使用彩色圆圈；过去的事项统一降低不透明度（不再用滤镜，保证浅色主题可读）。
- 重叠布局支持向右扩展：右侧列在整段时间内空闲时，块自动加宽；月视图按格子实际高度决定显示条数。
- 颜色：今天圆使用主题 `primary`，导航/小月历选中与悬停沿用共享侧栏的 `foreground/10`、`foreground/5`，阴影用 `shadow-*`；不写死 Google 蓝，日历色仍是用户数据。
- 宽度：页面宽度 < 1100px 时隐藏侧栏，< 900px 时隐藏任务面板（不提供 Sheet 或开关）；1100–1440px 之间两侧面板收窄为 240px 和 272px，三栏同时显示。
- 每小时 48px 是最小值：视图更高或工作时间较短时，时间轴自动拉伸铺满可见高度。
- 文案：已接入中英文 i18n（见 [实现记录](planning-calendar-implementation.md#多语言与命名)）；页面名称为「日历 / Calendar」。

## Agent 工具

`PlanningQuery` / `PlanningMutate` 已注册为内置工具（设置 → 内置工具，可在对话和定时任务中使用）。
为与界面一致，`PlanningQuery` 增加 `starred`（对应界面星标，即 `priority=high`）与 `overdue`
（对应今天的「N 项待处理任务」）过滤；其余能力见 [实现记录](planning-calendar-implementation.md#agent-工具)。

## Google 数据导入

- 一次性导入：日历页或设置中的「导入」直接接受 Google 日历导出的 `.zip`，以及 Google Takeout 的 `Tasks.json` / Takeout `.zip`（任务、列表、子任务、完成状态、截止日期）。
- 持续同步：设置中添加「订阅日历」，填入 Google「iCal 格式的私密地址」，作为只读日历定时刷新。
- 双向同步（Google Calendar / Tasks API + OAuth）暂不实现；细节见 [实现记录](planning-calendar-implementation.md#ical-订阅)。
