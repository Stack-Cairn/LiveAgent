# 日程：截止任务并入分栏 / 统一颜色管理

> 设计由 Fable 模型完成（2026-10-01），实现以本文为准。

## 1. 截止任务按统一格式参与分栏

**规则**：日列中所有定时条目（活动、任务排期块、定时任务虚拟活动、带截止时刻的任务胶囊）进入**同一次** `layoutEvents`。像素重叠即布局重叠，重叠者并排分栏、互不遮盖；每栏窄于 32px 时整簇退回错位层叠。胶囊保持 Google 式单行外观（22px、列表色实心、「○ 标题，hh:mm」），宽度服从分栏。

- **占用区间**：`[start, start + chipMs]`，`chipMs = (22 + 2)px / hourHeight × 1h`；像素高度与布局区间一致。起点钳制到 `to − chipMs`，避免列底溢出。
- **列序**：`layoutEvents` 排序为 起点升序 → 时长降序 → id，同起点时更长者在左，胶囊靠右。
- **层级**：胶囊不再固定浮在最上层（`zIndex = 2 + column`）。
- **已完成**：时间网格中的截止跟随「显示已完成的任务」，已完成显示勾选图标与删除线；逾期在无障碍名称中写明「已逾期」。
- **月视图**：截止与活动合并后按时间穿插排序（全天/按日截止在前）。日程视图已按时间穿插。
- **拖动截止**：本轮不做（预留 `DragState.kind: "due"`）。

## 2. 统一颜色管理

### 单一解析模块 `lib/planning/layers.ts`

- `LayerRef`：`calendar(id)` / `taskList(id, "" 为内置「我的任务」)` / `cron`。
- `layerColor(snapshot, ref, cronColor)`：唯一颜色来源；`eventColor`、`taskListColor` 为其薄封装。
- `listLayers(snapshot, cronColor)`：按「我的日历 → 任务列表 → 其他日历 → 定时任务」输出图层信息。
- `nextPaletteColor(used)`：新建列表/日历自动取未用颜色。
- `PLANNING_COLORS`（8 色）迁入该模块。

### 「日历与列表」管理对话框（由 CalendarManager 改造）

- 入口：侧栏「我的日历」旁的管理按钮、⋮ 面板第一项、设置 → 日程中的日历/任务列表行（可定位到某一行）。
- 左栏四个分组，每行：色点 + 名称 + 文字徽标（默认 / 订阅 / 本设备）。右栏按类型：
  - 本地日历：名称、颜色、活动默认通知、设为默认、删除（沿用）。
  - 订阅日历：名称、颜色（`subscription.update`）。
  - 任务列表：名称、颜色（`group.update`）；删除复用 `TaskListDialog`。
  - 内置「我的任务」：名称只读，颜色可改（新增 `mytasks.update`）。
  - 定时任务图层：显示开关 + 颜色，标注「仅本设备」。
- 可见性不进对话框，仍在侧栏 / ⋮ 面板（本地、按 Agent 作用域）。

### 其余入口

- 新建/重命名任务列表可选颜色，新建默认取未用颜色（不再全部是石板灰）。
- ⋮ 面板与设置页不再各自放定时任务颜色，改为跳转「日历与列表」。
- 颜色选择器使用单选组语义，色块以颜色名称命名，带非文字对比描边。

### 存储

| 对象 | 存储 |
| --- | --- |
| 日历 / 订阅 / 任务列表颜色 | Rust 快照（跨窗口、随备份） |
| 内置「我的任务」颜色 | Rust 元数据 `my_tasks_color`，快照字段 `myTasksColor` |
| 定时任务图层颜色 | 本地偏好 `planning.display.cronColor`（不属于任一 Agent 作用域的数据） |

Rust 侧统一校验颜色格式 `#RRGGBB`（`E:invalid_color`）。
