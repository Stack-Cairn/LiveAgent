# 后端队列迁移验收

## 本批实现

K-brain 通过 health 中的 `session_queue: 1` 声明队列能力。Gateway 仅保存前后端会话、请求、运行身份映射和事件游标，提交后由 K-brain 持久化并串行派发，不再同时维护可执行的本地 FIFO。

旧后端保留兼容路径；有未完成的旧队列或编辑时不自动转移所有权。已经使用后端队列的持久化状态不会因能力探测失败而退回旧执行器。4xx 明确拒绝会清除新建映射，连接或服务端错误保留映射供查询恢复，恢复不重新提交执行。

HTTP 服务关闭会调用协议服务和 Relay 的关闭入口，取消队列读取与 SSE 订阅并等待退出，不取消独立后端已经接受的任务。后端进程自身的生命周期仍由它的启动者管理。

## 尚未完成与发现的问题

- 桌面本地队列入口仍未迁移；没有完成原生 macOS 包的端到端验收。
- Gateway 文本请求尚未接通附件的 canonical content 解析。
- 后端重启后队列默认暂停；下一批已补 WebUI 暂停/恢复按钮，见下节。
- 旧队列排空后重新协商能力仍需重启 Gateway。
- 后端队列读取仍依赖会话运行时可加载，未独立处理凭据失效、旧模型删除的只读访问。
- 收据达到 4096 上限会明确拒绝提交；自动归档仍需设计，不能直接删除去重身份。
- 实际 WebUI 控制台仍有远程目标的后台进程初始化、轨迹统计 `agent offline`，属于现有远程功能适配缺口。它们未阻断本次聊天队列验收，不能据此声称所有页面功能可用。
- 测试使用 Chat Completions 模型时显式关闭联网；若开启当前不支持的原生联网，后端明确报错。本次没有测试线上模型、真实工具或缓存命中率。

本批仅本地实现与验证，不代表已合入远端 main/v2 或发布。

## 后续批次：暂停、恢复与刷新身份同步

### 实现

- 队列快照保留可选 `paused` 字段。只有声明此字段的后端队列显示控制按钮，旧桌面执行器不会显示不可用入口。
- WebUI 主输入区、工作台主会话与背景会话均接入暂停/恢复，使用当前 revision 提交。后端对 pause/resume 的显式 0 revision 同样执行冲突校验，不再替换成最新值。
- 暂停只阻止派发后续项，不中断正在运行的任务；暂停时点“停止”只取消当前任务，不隐式恢复或打断执行下一项。空队列处于暂停状态时保留恢复按钮。
- 操作在途禁用重复点击；冲突采用后端快照更新，失败给出提示，并读取队列核对“后端已提交但回执丢失”的情况。
- 分屏队列按钮保留当前面板焦点，暂停/恢复直接定位按钮所属会话，修复后台面板首次点击因焦点切换而失效的问题。
- 修复刷新恢复使用 canonical 会话 ID，而队列事件仍使用旧 Gateway alias 的问题。快照向同一后端会话的各身份广播；各次投影独立复制，不修改源快照。canonical 页面尚未读取历史时也能验证后端会话并操作队列项。
- 已接受运行的 SSE 同样转发 `queue.updated`，不同客户端的暂停、恢复和删除状态可以同步。
- 修复事件游标写回覆盖 POST 回执中 item ID，以及并发终态后回执重新写入已结束映射的问题。
- 新增桌面 TypeScript 客户端队列方法：读取、收据查询、可取消的长轮询、提交、revision 动作。提交遇连接或响应体中断时只 GET 查询接受收据，不重复 POST；动作失败不自动重放修改。
